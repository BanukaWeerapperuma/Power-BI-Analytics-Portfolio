# 📊 Power BI Analytics Portfolio

Welcome to my analytics portfolio! This repository showcases end-to-end data analytics projects featuring robust SQL data modeling, advanced Power BI dashboards, and interactive visual insights.

---

## 🧭 About the Portfolio

This portfolio serves as a centralized hub for my business intelligence work. Each project is built from scratch—starting from raw data extraction and SQL transformation to clean relational modeling and fully interactive Power BI reports designed to drive data-backed decision-making.

---

## 🛠️ Technologies & Tools

* **Data Engineering & Analytics Platform:** Microsoft Fabric (Lakehouse, Data Warehouse)
* **Data Visualization & BI:** Power BI, DAX, Power Query
* **Database & Querying:** SQL, Relational Modeling
* **Data Processing & Formats:** CSV, Excel
* **Version Control & Documentation:** Git, GitHub Markdown
